# Carnet Faune

Première version Android du carnet d'observations naturalistes.

Fonctions incluses : observation (espèce, lieu, nombre, notes, GPS), historique local, graphique par heure et ouverture de carte.

La liste d'espèces est un catalogue de démarrage et n'est pas la liste complète de la faune métropolitaine.

Le workflow GitHub Actions construit automatiquement l'APK debug après chaque push ou manuellement.
